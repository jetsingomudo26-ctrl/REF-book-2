# Pustaka Pelajar

Pustaka Pelajar adalah sebuah aplikasi web ringan yang dirancang untuk membantu pelajar, mahasiswa, dan pendidik dalam mencari serta menemukan referensi buku, makalah, biografi tokoh, dan karya ilmiah secara cepat dan terstruktur. Website ini dibangun dengan pendekatan modern, responsif, serta berfokus pada kemudahan akses informasi akademis.

## Fitur Utama

- **Pencarian Real-Time**: Memungkinkan pengguna mencari referensi buku secara instan berdasarkan judul buku, nama penulis, atau topik makalah yang diinginkan.
- **Filter Kategori**: Pengelompokan materi berdasarkan bidang studi dan kategori tertentu seperti Sejarah, Biografi, Sains, Ekonomi, dan Sastra.
- **Desain Responsif**: Antarmuka pengguna yang bersih dan minimalis, dirancang agar nyaman diakses melalui perangkat seluler maupun komputer desktop.
- **Akses Langsung**: Tombol tautan cepat untuk mengakses, melihat detail, atau mengunduh materi referensi yang dibutuhkan.
